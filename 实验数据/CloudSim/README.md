# CloudSim 实验结果

- `data/冷启动_3990行.csv`：19 个任务规模 × 30 个种子 × 7 个方法。
- `data/冷启动_敏感性_3060行.csv`：2250 条权重敏感性记录及 810 条 VM 容量敏感性记录。
- `data/主实验实例参数.csv`、`敏感性实例参数.csv`：实例与任务参数；对应协议 CSV 保留完整运行元数据。
- `data/图表与统计汇总/`：CSV/JSON 数值汇总、置信区间、成对比较、运行时间和直接精修诊断。
- `data/直接精修_4500条计时.csv`、`直接精修_900条质量.csv`：重复计时及去重质量记录。
- `data/成本模型追加验证/`：公式筛选、冻结模型与新种子验证记录。
- `figures/`：Fig6、Fig7、Fig8 的独立 PDF/SVG/PNG、曲线坐标及版式信息。

Greedy-LPT 记录保留为目标归一化参考。每个方法的曲线身份、颜色和线宽均可通过原始记录和矢量文件核验。Cost 使用合成成本单位；Load imbalance 为完工时间标准差与均值之比，无单位。

在仓库根目录运行 `实验代码/CloudSim程序/scripts/verify_latest.py` 核验数据。新模拟、分析和绘图输出写入仓库外的运行目录。
